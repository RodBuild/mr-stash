## Advanced Usage: `asChild`

By applying the `asChild` prop, the component will pass all styling, states, and action listeners onto its direct child. This is highly useful when using client-side routing libraries like Next.js `Link` or standard `<a>` tags.

For example, this story renders the button as an anchor tag:

<Canvas of={ButtonStories.AsChildLink} />

```tsx
import { Button } from "@mr-stash/ui"

// Renders: <a href="https://google.com" class="border border-input bg-background ...">Google</a>
;<Button asChild variant="outline">
  <a href="https://google.com">Google</a>
</Button>
``` */}
